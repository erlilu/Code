# 迭代器
## 迭代器基础知识
1. 知识点1：能被 for 循环遍历的对象，能被为：可迭代对象(iterable)。
2. 知识点2：可迭代对象(iterable) 能调用到 __iter__ 方法。
3. 知识点3: 调用 __iter__ 方法会得到：迭代器(iterator).
   - 备注1: __iter__ 是一个魔法方法，当调用iter函数时，__iter__会自动调用。
   - 备注2: 可迭代对象.__iter__() 等价于 iter(可迭代对象)。
   - 备注3: 如果iter(obj)能得到一个迭代器(iterator)，那obj就是可迭代对象。【推荐】
4. 知识点4: 迭代器(iterator)拥有 __next__ 方法，每次调用都会根据当前的状态，返回下一个元素。
   - 备注1: 迭代器.__next__ 等价于 next(迭代器)
5. 知识点5:迭代器(iterator)也拥有 __iter__方法，并且其返回值是迭代器自身。

## 迭代器特点
1. 迭代器是一次性的，状态只会向前推进，且不会自动重置。
2. for循环本质是生成一个单独迭代器【只要调用的不是同一个迭代器对象，就可以多次全部调用】

## 迭代器的优势
1. 迭代器是惰性计算，不会一次性生成所有结果，所以能显著降低内存占用。
2. 当数据量很大，不确定用多少结果时，推荐使用迭代器。

# 生成器
1. 生成器函数:函数体中如果出现了 yield 关键字，那该函数是「生成器函数」。
2. 生成器对象：调用「生成器函数」时，其函数体不会立刻执行，而是返回一个「生成器对象」。
   - 备注：不管能否执行到yield所在的位置，只要函数中有yield关键字，那该函数，就是「生成器函数」。
3. 写在生成器函数中的代码，需要通过生成器对象来执行：
   1. 调用生成器对象的__next__方法，会让生成器函数中的代码开始执行。
   2. 当生成器函数中的代码开始执行后，遇到yield会暂停执行，并且其内部会记录暂停的位置。
   3. 后续调用__next__方法时，都会从上一次暂停的位置，继续运行，直到再次遇到yield。
   4. 遇到return 会抛出 StopIteration: 异常，并将return后面的表达式，作为异常信息返回。
   5. yield 后面缩写的表达式，会作为本次__next__方法的返回值。【没有写，默认为None】
4. 生成器对象是一种特殊的迭代器(本质是通过 yield 自动实现了迭代器协议)。
5. yield 也能写在循环里
6. yield from 能把一个可迭代对象里的东西依次 yield 出去。(替代：for + yield)
7. 使用：生成器.send(value)可以让生成器继续执行的同时，给上一次yield传值
   - 备注1:next只能取值，send既能取值，也能送值。
   - 备注2:第一次启动生成器，不能传值。
