## 文件操作
### python中操作文件的标准流程
1. 创建文件对象
2. 操作文件（读取、写入 等）
3. 关闭文件

### 文件操作的核心
> open函数：他是可以打开或者创建文件，且支持多种操作模式，返回值是文件对象。

参数如下：
1. file：要操作的文件路径
2. mode：文件的打开模式
   - r：读取（默认值）
   - w：写入，并先截断文件【截断文件 == 清空文件】
   - x：排它性创建，如果文件已存在，则创建失败。
   - a：打开文件用于写入，如果文件存在，则在文件末尾追加内容
   - b：二进制模式
   - t：文本模式（默认值）
   - +：打开用于更新（读取与写入）
3. encoding：字符编码

### 读取文件
> read 方法说明：
1. read(size) 中的size是可选参数
   - 若不传递 size 参数，表示：读取文件中所有的内容（注意内存占用）
   - 若传递了 size 参数，表示：读取文件中制定个数的字符，或制定大小的字节。
   - 【备注】：用循环配合多次read，对内存友好
2. read 会从上一次 read 的位置继续读取（指针思想），若到达文件末尾后继续读取，将返回空字符串。

> readline方法说明：使用文件对象的 readline方法，读取文件中的一行。
1. readline(size) 中的size是可选参数。
   - 若不传递 size 参数，表示：读取这一行中所有的内容（注意内存占用）
   - 若传递了 size 参数，表示：读取当前行时，最多能读取的字符数，或字符数。
2. readline 方法，也是从上一次位置继续读取，若到达文件末尾后继续读取，也返回空字符串。 
3. repr()可以全部显示当行、strip()代替空格和\n
4. 可以通过循环配合readline逐行读取。

> readlines 方法说明：使用文件对象的 readlines 方法，一次性按行读完，返回一个列表。
1. readlines(hint) 中的 hint 是可选参数。
   - 若不传递 hint 函数，表示：读取当前文件的所有行。
   - 若传递了hint参数，表示：期望读取的【字符个数 或 字节数的上限】hint不是行数。
2. 注意：由于 readlines 是一次性读取文件的所有内容，所以不适合读取提及较大的文件。
 
> 最佳实践：使用 with 上下文管理器，结合for循环遍历，逐行读取文件。

### 写入文件
【在 python 中文件写入时，并不是每写一次就立刻落盘，而是：先写到“缓冲区”里。】
1. 文件对象的 flush 方法：把缓冲区中的数据，立刻写入文件中。
2. seek(offset, whence)方法：用于改变文件对象指针的位置，参数说明如下：
   - offset: 偏移量，要移动多少距离
   - whence：参考点，从哪里开始计算偏移，有三种取值：
     - 0:从文件开头计算（默认值）
     - 1:从当前位置计算
     - 2:从文件末尾计算
   【注意：在文本模式下，不要随意去定位中文字符位置，否则可能破坏文件编码】

### 目录操作
1. os.mkdir(path): 创建单级目录（如果目录已经存在，则会抛出异常）
2. os.makedirs(path): 创建多级目录（如果路径中的所有目录都已经存在，则会抛出异常）
3. os.rmdir(path): 删除空目录（如果目录不存在，或目录非空，都会抛出异常）
4. os.removedirs(path): 递归删除空目录，在成功删除末尾一级目录后，会**向上**尝试把父级目录也删除（知道父目录不是空目录）
5. os.path.exits(path): 判断路径是否存在（文件/目录都算）【返回的是bool】
6. os.path.isdir(path): 用于判断路径，具体规则如下：
   - 路径不存在 =======> 返回 False
   - 路径存在，但指向的是文件 ======> 返回 False
   - 路径存在，并且是目录 ======> 返回 True
7. os.path.isfile(path): 判断是否为文件【返回的是bool】
8. os.scandir(path): 扫描制定目录
9. os.walk(path): 按层级，递归地遍历指定目录下，所有的子目录和文件。
10. ⚠️危险操作：删除有内容的目录 shutil.rmtree(path)
## with
1. python中的with主要用于管理程序中“需要成对出现的操作”，例如：
   - 上锁 / 解锁
   - 打开 / 关闭
   - 借用 / 归还
2. 最终目标：编码者只管做具体的事，“进入”和“离开”的事，让 python 自动处理。
3. 语法格式如下：
``` 
with 能得到一个上下文管理器的表达式 as 变量：
   具体的事1
   具体的事2
   具体的事3
```
4. 上下文管理器协议
   - __enter__ 方法：with 中的代码执行【之前】调用，其返回值会赋值给 as 后的变量.
   - __exit__ 方法：with 中的代码执行【结束后】调用（无论是 with 中是否出现异常都会调用）
5. 当with中的代码发生异常时，__exit__ 方法的返回值规则如下：
   - 返回“真”：表示异常**已经**被处理，异常**不会**被继续抛出。
   - 返回“假”：表示异常**没有**被处理，异常**会**被继续抛出。
6. with 的步骤：
   1. 计算 with 后面的表达式，得到一个上下文管理器。
   2. 调用上下文管理器的 __enter__()方法，并将其返回值赋给 as 后面的变量。
   3. 执行 with 所管理的代码。
   4. 无论代 with 中的代码，是正常结束，还是发生异常，都会自动调用上下文管理的 __exit__ 方法。
